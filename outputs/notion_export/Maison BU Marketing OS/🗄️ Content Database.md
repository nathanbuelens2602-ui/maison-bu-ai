# 🗄️ Content Database

> *De kern van het systeem. Alle content zit hier in.*

---

## Hoe werkt deze database?

Maak een nieuwe **Notion database** op deze pagina met de onderstaande properties. Gebruik de **Board view** (gegroepeerd op Status) als hoofdweergave.

---

## Properties (kolommen)

| Property | Type | Opties |
|---|---|---|
| **Titel** | Titel | De naam van het stuk |
| **Type** | Select | Feedpost · Reel · Story · E-mail · Shootdag |
| **Status** | Select | 💡 Idee · ✏️ In productie · ✅ Klaar · 👀 Wacht op goedkeuring · 📣 Gepubliceerd |
| **Publicatiedatum** | Datum | Exacte datum + tijd |
| **Week** | Select | Week 1 · Week 2 · Week 3 · Week 4 |
| **Platform** | Multi-select | Instagram Feed · Instagram Story · Instagram Reel · E-mail |
| **Pillar** | Select | De Maison · De Craft · De Gast · Kristof · Ceremonie |
| **CTA** | Select | Geen · Fluistering · Weloverwogen · Uitnodiging |
| **Caption** | Tekst | De volledige caption |
| **Hashtags** | Tekst | De hashtags |
| **Visueel** | Tekst | Beschrijving van het beeld of video |
| **Asset link** | URL | Link naar Canva / Google Drive |
| **Goedgekeurd** | Checkbox | ✓ wanneer goedgekeurd |
| **Campagne** | Select | De Zoetheid van Juni · [volgende campagne] |
| **Noten** | Tekst | Extra opmerkingen |

## Views (aan te maken in Notion)

| View naam | Type | Filter | Groepering |

| **Board — Status** | Board | Alles | Status |

| **Board — Week** | Board | Huidige maand | Week |
| **Tabel — Alles** | Table | Alles | — |
| **Reel** | Table | Type = Reel | — |
| **Feedpost** | Table | Type = Feedpost | — |
| **Story** | Table | Type = Story | — |
| **Vandaag** | Table | Publicatiedatum = vandaag | — |
| **Klaar te posten** | Table | Status = Klaar | Platform |
